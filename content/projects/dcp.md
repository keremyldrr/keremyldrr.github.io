The goal of the project was to conduct experiments and analyze their results on the DCP architecture by Wang et al. Mixamo dataset was used to retrain the model and some tests were also done with the TUM RGBD dataset. Tried adding different regularizations, adding color as an additional input signal, and different sampling of points to improve the performance of the model in real-life scenarios.

**Original paper:** [Deep Closest Point: Learning Representations for Point Cloud Registration](https://openaccess.thecvf.com/content_ICCV_2019/papers/Wang_Deep_Closest_Point_Learning_Representations_for_Point_Cloud_Registration_ICCV_2019_paper.pdf)
